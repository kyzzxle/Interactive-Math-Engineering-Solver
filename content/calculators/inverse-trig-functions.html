What the inverse trig calculator does

An inverse trigonometric function answers the question “which angle has this sine (or cosine, or tangent)?”. Because sine, cosine and tangent repeat, infinitely many angles share each value, so each inverse is defined to return one principal value from a restricted range.

\(\sin^{-1}\) and \(\cos^{-1}\) accept only values from −1 to 1 — no angle has a sine of 2. \(\tan^{-1}\) accepts any real number.

Formulas and variables

\[ y = \sin^{-1} x \iff \sin y = x,\ y \in \left[-\tfrac{\pi}{2}, \tfrac{\pi}{2}\right] \]\[ y = \cos^{-1} x \iff \cos y = x,\ y \in [0, \pi] \qquad y = \tan^{-1} x \iff \tan y = x,\ y \in \left(-\tfrac{\pi}{2}, \tfrac{\pi}{2}\right) \]
SymbolMeaning
\(x\)The ratio (input)
\(y\)The principal angle (output)
\(n\)Any integer, for the full set of solutions

All solutions of \(\sin\theta = x\): \(\theta = \sin^{-1}x + 2\pi n\) or \(\pi - \sin^{-1}x + 2\pi n\).

Worked example

Find arccos(−1/2)

Step 1 — Domain

\(-\tfrac{1}{2}\) lies in \([-1, 1]\), so the value exists.

Step 2 — Reference angle

\[ \cos\tfrac{\pi}{3} = \tfrac{1}{2} \]

Step 3 — Correct quadrant

Cosine is negative in quadrant II, and the range of arccos is \([0, \pi]\):

\[ \cos^{-1}\left(-\tfrac{1}{2}\right) = \pi - \tfrac{\pi}{3} = \tfrac{2\pi}{3} = 120^\circ \]

Domain, special cases and common mistakes

  • arcsin and arccos need −1 ≤ x ≤ 1; arctan accepts any real x.
  • Exact answers are shown for the standard values (multiples of 15°).

Common mistakes

  • Reading \(\sin^{-1}x\) as \(1/\sin x\) — that is \(\csc x\).
  • Giving an angle outside the principal range, e.g. arcsin(−½) = 330° instead of −30°.
