What are radical and rational equations?

A radical equation has the unknown under a root, such as \(\sqrt{x + 7} = x + 1\). A rational equation has the unknown in a denominator, such as \(\tfrac{3}{x + 1} = \tfrac{2}{x - 1}\). Both are solved by turning them into ordinary polynomial equations: square both sides, or multiply by the denominators. Both steps can introduce extraneous roots, answers that do not satisfy the original equation, so every candidate must be checked.

Why extraneous roots appear

Squaring loses the sign. \(2\) and \(-2\) have the same square, so \(\sqrt{u} = v\) and \(\sqrt{u} = -v\) both become \(u = v^2\). The squared equation has the solutions of both, and only those with \(v \ge 0\) belong to the original.

Multiplying by an expression that can be 0. Multiplying both sides by \(x - 1\) is only reversible when \(x \ne 1\). A root that makes a denominator 0 was never allowed in the original equation.

Graph view

The squared equation describes where the line meets the whole sideways parabola \(y^2 = ax + b\). The square root is only its upper half, so crossings with the lower half are extraneous.

How the methods work

Radical equations

Isolate the root first. Squaring \(\sqrt{ax + b} = cx + d\) gives

\[ ax + b = c^2x^2 + 2cdx + d^2 \;\Rightarrow\; c^2x^2 + (2cd - a)x + (d^2 - b) = 0, \]

a quadratic (or a linear equation when \(c = 0\)). Solve it and test each root in the original equation.

Rational equations

Write each side as one fraction, then multiply both sides by the LCD. The fractions clear, leaving a polynomial equation. Solve it and discard any root that is an excluded value.

Complete worked example

Problem

Solve \(\sqrt{x + 7} = x + 1\).

Step 1: Square both sides

\[ x + 7 = x^2 + 2x + 1 \]

Step 2: Solve the quadratic

\[ x^2 + x - 6 = 0 \;\Rightarrow\; (x + 3)(x - 2) = 0 \;\Rightarrow\; x = -3 \text{ or } x = 2 \]

Step 3: Check

\(x = 2\): \(\sqrt{9} = 3\) and \(2 + 1 = 3\). ✓

\(x = -3\): \(\sqrt{4} = 2\) but \(-3 + 1 = -2\). Rejected.

The solution is \(x = 2\).

Second worked example: a rational equation

Problem

Solve \(\tfrac{x}{x - 1} = \tfrac{1}{x - 1} + 2\).

Step 1: Excluded value

The denominator is 0 at \(x = 1\), so \(x \ne 1\).

Step 2: Multiply every term by the LCD, \(x - 1\)

\[ x = 1 + 2(x - 1) \;\Rightarrow\; x = 2x - 1 \;\Rightarrow\; x = 1 \]

Step 3: Check

\(x = 1\) is the excluded value, so it is rejected. The equation has no solution: for every other \(x\) the left side is \(1 + \tfrac{1}{x - 1}\), which never equals \(\tfrac{1}{x - 1} + 2\).

Practical applications

  • Pendulums and free fall: \(T = 2\pi\sqrt{L/g}\) and \(t = \sqrt{2h/g}\) are solved for a length or height.
  • Lenses: the thin-lens equation \(\tfrac{1}{f} = \tfrac{1}{d_o} + \tfrac{1}{d_i}\) is a rational equation.
  • Resistors in parallel and work rates: \(\tfrac{1}{R} = \tfrac{1}{R_1} + \tfrac{1}{R_2}\) has the same form as "two pipes fill a tank".
  • Average speed: trips at different speeds give equations with the unknown in a denominator.

Common mistakes

  1. Squaring term by term. \((x + 1)^2 = x^2 + 2x + 1\), not \(x^2 + 1\).
  2. Squaring before isolating the root. Get the root alone on one side first.
  3. Not checking the answers. Squaring and clearing denominators can both add roots.
  4. Forgetting the excluded values. Write them down before you multiply anything.

Assumptions and limitations

  • Radical mode handles a single square root of a linear expression equal to a linear expression.
  • Rational mode accepts polynomials and whole-number powers in \(x\); after clearing denominators the degree must be at most 8.
  • Rational roots are exact; other roots are found numerically and shown to 6 decimal places.

Frequently asked questions

What is an extraneous solution?

A value that solves the equation after squaring or clearing denominators, but not the original equation.

How do I solve a square root equation?

Isolate the root, square both sides, solve the resulting equation, then substitute each answer into the original equation.

How do I solve an equation with fractions that contain x?

Note the excluded values, multiply every term by the least common denominator, solve, and reject any excluded value.

Can a radical equation have no solution?

Yes. If every candidate is extraneous, as in √(x) = −2, there is no solution.
