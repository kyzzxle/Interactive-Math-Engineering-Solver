What is a linear equation?

A linear equation in one variable can be written as \(ax + b = 0\): \(x\) appears only to the first power, never squared, under a root or in a denominator. It has exactly one solution unless the \(x\)-terms cancel, in which case it has no solution or infinitely many. Solving it means getting \(x\) by itself while keeping both sides balanced.

Try changing the input

Enter \(2(x + 1) = 2x + 5\). The \(2x\) terms cancel and leave \(2 = 5\), which is false: no value of \(x\) works.

What this calculator does

  • Accepts an equation with brackets, fractions and decimals, such as \(2(x - 3) + 4 = 5x - 11\).
  • Expands and simplifies each side, collects terms and solves exactly.
  • Detects equations with no solution or infinitely many.
  • Checks the answer in the original equation and graphs each side as a line.

The idea behind it

An equation is a balance. Adding, subtracting, multiplying or dividing both sides by the same thing (except dividing by 0) keeps it balanced, so the solution does not change. The plan is always the same:

  1. Clear brackets and fractions.
  2. Collect the \(x\)-terms on one side and the numbers on the other.
  3. Divide by the coefficient of \(x\).

Graph view

Each side is a straight line. The solution is the \(x\)-value where the lines cross. Parallel lines never cross (no solution); identical lines cross everywhere (every \(x\)).

Formula breakdown

\[ ax + b = cx + d \;\Rightarrow\; (a - c)x = d - b \;\Rightarrow\; x = \frac{d - b}{a - c} \]

Why the steps work

Start from \(ax + b = cx + d\). Subtract \(cx\) from both sides: \(ax - cx + b = d\). Subtract \(b\): \((a - c)x = d - b\). If \(a - c \ne 0\), divide by it to get the formula. If \(a - c = 0\), the left side is \(0\), and the equation is true only when \(d - b = 0\) as well.

Clearing fractions

Multiplying every term by the least common denominator removes all fractions at once. For \(\tfrac{x}{2} + \tfrac{1}{3} = \tfrac{3}{4}\), multiply by 12: \(6x + 4 = 9\).

Complete worked example

Problem

Solve \(2(x - 3) + 4 = 5x - 11\).

Step 1: Expand and simplify

\[ 2x - 6 + 4 = 5x - 11 \;\Rightarrow\; 2x - 2 = 5x - 11 \]

Step 2: Collect terms

\[ 2x - 5x = -11 + 2 \;\Rightarrow\; -3x = -9 \]

Step 3: Divide

\[ x = \frac{-9}{-3} = 3 \]

Check

Left: \(2(0) + 4 = 4\). Right: \(15 - 11 = 4\). ✓

Second worked example: fractions

Problem

Solve \(\tfrac{x}{2} + \tfrac{1}{3} = \tfrac{3}{4}\).

Step 1: Multiply every term by 12

\[ 6x + 4 = 9 \]

Step 2: Solve

\[ 6x = 5 \;\Rightarrow\; x = \frac{5}{6} \approx 0.8333 \]

Check

\(\tfrac{5}{12} + \tfrac{4}{12} = \tfrac{9}{12} = \tfrac{3}{4}\). ✓

Practical applications

  • Costs: a fixed fee plus a rate per unit, solved for the number of units.
  • Temperature conversion: \(F = \tfrac{9}{5}C + 32\) solved for \(C\).
  • Uniform motion: distance = speed × time, for meeting and catching-up problems.
  • Linear calibration: reading a quantity from a sensor with a straight-line response.

Common mistakes

  1. Distributing only to the first term. \(2(x - 3) = 2x - 6\), not \(2x - 3\).
  2. Changing the side without changing the sign. Moving \(+5x\) across gives \(-5x\).
  3. Doing something to one side only. Every operation must be done to both sides.
  4. Multiplying only some terms by the LCD. Every term, on both sides, is multiplied.

Assumptions and limitations

  • The equation uses the variable \(x\) and must reduce to a linear one; higher powers must cancel.
  • Fractions and decimals are handled exactly; the answer is a fraction, with a decimal when it terminates.
  • For \(x\) in a denominator, use the rational equation solver.

Frequently asked questions

How do I solve a linear equation?

Expand brackets, clear fractions, collect x-terms on one side and numbers on the other, then divide by the coefficient of x.

When does a linear equation have no solution?

When the x-terms cancel and leave a false statement such as 2 = 5. The two sides are parallel lines.

What does infinitely many solutions mean?

Both sides simplify to the same expression, so every value of x makes the equation true.

How do I check my answer?

Substitute it into the original equation. Both sides must give the same number.
