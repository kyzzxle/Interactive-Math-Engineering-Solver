Checking and simplifying trigonometric identities

A trigonometric identity is an equation that is true for every angle where both sides are defined, such as \(\sin^2 x + \cos^2 x = 1\). This tool helps in two ways: it rewrites expressions in terms of \(\sin x\) and \(\cos x\) — the usual first step of a proof — and it tests the equation at dozens of angles. If any angle fails, you get a counterexample, which proves the equation is not an identity. In simplify mode, the expression is compared against a list of common simple forms.

Try changing the input

Check \(\sin 2x = 2\sin x\) (false) and then \(\sin 2x = 2\sin x\cos x\) (true). The graph shows the two curves separating or lying exactly on top of each other.

Supported identities

TypeIdentities
Reciprocal\(\sec x = \frac{1}{\cos x}\), \(\csc x = \frac{1}{\sin x}\), \(\cot x = \frac{1}{\tan x}\)
Quotient\(\tan x = \frac{\sin x}{\cos x}\), \(\cot x = \frac{\cos x}{\sin x}\)
Pythagorean\(\sin^2 x + \cos^2 x = 1\), \(1 + \tan^2 x = \sec^2 x\), \(1 + \cot^2 x = \csc^2 x\)
Double angle\(\sin 2x = 2\sin x\cos x\), \(\cos 2x = \cos^2 x - \sin^2 x = 1 - 2\sin^2 x\)

Expressions may use \(\sin, \cos, \tan, \sec, \csc, \cot\), numbers, \(+, -, \times, \div\) and powers, with \(x\) as the angle.

Worked example

Simplify \(\dfrac{1 - \cos^2 x}{\sin x}\)

Step 1 — Pythagorean identity

\[ 1 - \cos^2 x = \sin^2 x \]

Step 2 — Cancel

\[ \frac{\sin^2 x}{\sin x} = \sin x \quad (\sin x \ne 0) \]

How reliable is it?

  • "Not an identity" is certain: the tool shows an angle where the two sides differ.
  • "Identity" means the sides agreed (to within \(10^{-9}\) relative error) at about 60 angles spread over \((-2\pi, 2\pi)\). This is very strong evidence but not a written proof; use the table above to build one.
  • Simplification only recognises the common simple forms the tool tests against (such as \(1\), \(\sin x\), \(\sec^2 x\), \(\sin 2x\)). If none matches, it says so instead of guessing.
  • Angles where an expression is undefined (for example \(\tan x\) at \(\frac{\pi}{2}\)) are skipped.
