What the partial fraction calculator does

Partial fraction decomposition rewrites a rational function as a sum of simpler fractions, one for each factor of the denominator. It is the key step in integrating rational functions and in inverse Laplace transforms.

Each linear factor (x − r) contributes A/(x − r); a repeated factor (x − r)ᵐ contributes one term for each power up to m; an irreducible quadratic factor contributes (Bx + C)/(quadratic). The unknown coefficients are found by matching coefficients — exactly, here.

Try it

Check a decomposition by adding the fractions back over the common denominator.

Formulas and variables

\[ \frac{P(x)}{(x - r)^m\,(x^2 + px + q)} = \frac{A_1}{x - r} + \cdots + \frac{A_m}{(x - r)^m} + \frac{Bx + C}{x^2 + px + q} \]
SymbolMeaning
\(A_i,\ B,\ C\)Unknown constants
\(r\)Rational root of the denominator
\(x^2 + px + q\)Quadratic factor with no rational roots

If the numerator’s degree is not lower than the denominator’s, divide first: the decomposition is then polynomial + proper fraction.

Worked example

Decompose (3x + 5)/(x² + x − 2)

Step 1 — Factor and set up

\[ \frac{3x + 5}{(x + 2)(x - 1)} = \frac{A}{x + 2} + \frac{B}{x - 1} \]

Step 2 — Clear denominators

\[ 3x + 5 = A(x - 1) + B(x + 2) \]

Step 3 — Solve

At \(x = 1\): \(8 = 3B\), so \(B = \tfrac{8}{3}\). At \(x = -2\): \(-1 = -3A\), so \(A = \tfrac{1}{3}\).

\[ \frac{3x + 5}{x^2 + x - 2} = \frac{1}{3(x + 2)} + \frac{8}{3(x - 1)} \]

Domain, special cases and common mistakes

  • Denominators up to degree 6 that factor into linear factors with rational roots plus at most one quadratic factor.
  • Denominators with a cubic or higher factor that has no rational root are not supported.

Common mistakes

  • Using a constant (not Bx + C) over a quadratic factor.
  • Forgetting the lower powers of a repeated factor.
