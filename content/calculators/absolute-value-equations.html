What is an absolute value equation?

The absolute value \(|u|\) is the distance of \(u\) from 0 on the number line, so it is never negative: \(|5| = 5\) and \(|-5| = 5\). An absolute value equation such as \(|2x - 3| = 7\) asks which values of \(x\) put \(2x - 3\) exactly 7 units from 0. Because there are two numbers at that distance, 7 and −7, these equations usually have two solutions.

Try changing the input

Make the right side negative, for example \(|x - 1| = -4\). No number has a negative distance from 0, so there is no solution.

What this calculator does

  • \(|ax + b| = k\): two cases, or none when \(k\) is negative.
  • \(|ax + b| = cx + d\): two cases, then rejects any candidate that makes the right side negative.
  • \(|ax + b| = |cx + d|\): the two expressions are equal or opposite.
  • \(|ax + b| \lt k\), \(\le\), \(\gt\) or \(\ge\): the solution set in inequality and interval notation.

Every answer is exact and checked, and the graph shows where the V-shaped graph of \(|ax + b|\) meets the other side.

The idea behind it

The definition of absolute value splits into two cases:

\[ |u| = \begin{cases} u & \text{if } u \ge 0 \\ -u & \text{if } u \lt 0 \end{cases} \]

So \(|u| = k\) (with \(k \ge 0\)) means \(u = k\) or \(u = -k\). On a graph, \(y = |ax + b|\) is a V with its vertex on the x-axis at \(x = -\tfrac{b}{a}\). A horizontal line \(y = k\) above the vertex cuts the V twice; a line through the vertex touches it once; a line below the axis misses it.

Distance on the number line

\(|x - 3| \lt 2\) means "x is less than 2 units from 3", so \(1 \lt x \lt 5\). \(|x - 3| \gt 2\) means "more than 2 units away": \(x \lt 1\) or \(x \gt 5\).

Why the cases work

Equations

If \(|u| = k\) with \(k \ge 0\), then either \(u \ge 0\), so \(|u| = u = k\), or \(u \lt 0\), so \(|u| = -u = k\) and \(u = -k\). Those are the two cases.

Why some candidates are rejected

For \(|u| = v\), each case is solved as if \(v\) could be anything. But \(|u|\) is never negative, so a candidate that makes \(v\) negative cannot be a solution. It is extraneous.

Inequalities

\(|u| \lt k\) says \(u\) lies within \(k\) of 0, which is the double inequality \(-k \lt u \lt k\). Subtract \(b\) from every part and divide by \(a\); if \(a\) is negative, the inequality signs reverse.

Complete worked example

Problem

Solve \(|x - 4| = 2x + 1\).

Step 1: Case 1, the inside equals the right side

\[ x - 4 = 2x + 1 \;\Rightarrow\; x = -5 \]

Step 2: Case 2, the inside equals minus the right side

\[ x - 4 = -(2x + 1) \;\Rightarrow\; 3x = 3 \;\Rightarrow\; x = 1 \]

Step 3: Check both candidates

\(x = -5\): the right side is \(2(-5) + 1 = -9\), which is negative, so it is rejected.

\(x = 1\): \(|1 - 4| = 3\) and \(2(1) + 1 = 3\). ✓

The only solution is \(x = 1\).

Second worked example: an inequality

Problem

Solve \(|2x - 1| \lt 5\) and write the answer in interval notation.

Step 1: Write a double inequality

\[ -5 \lt 2x - 1 \lt 5 \]

Step 2: Add 1 to every part, then divide by 2

\[ -4 \lt 2x \lt 6 \;\Rightarrow\; -2 \lt x \lt 3 \]

Step 3: Interval notation

\((-2, 3)\), with round brackets because the endpoints are not included.

Check

\(x = 0\) is inside: \(|-1| = 1 \lt 5\). ✓ \(x = 4\) is outside: \(|7| = 7 \gt 5\). ✓

Practical applications

  • Tolerances: a shaft of nominal diameter 25 mm with a tolerance of 0.02 mm must satisfy \(|d - 25| \le 0.02\).
  • Error bounds: a measurement within 3% of the true value.
  • Control and quality limits: a temperature kept within 2 °C of a set point.
  • Distances: points on a line within a given distance of a landmark.

Common mistakes

  1. Solving only one case. \(|u| = k\) almost always has two solutions.
  2. Negating only part of the right side. The second case is \(u = -(cx + d)\), with brackets.
  3. Skipping the check. With \(x\) on the right side, a candidate can be extraneous.
  4. Writing a "greater than" answer as one interval. \(|u| \gt k\) gives two separate pieces joined by "or".

Assumptions and limitations

  • The expressions inside and outside the absolute value are linear, \(ax + b\) and \(cx + d\).
  • \(a\) cannot be 0. Coefficients may be fractions; all answers are exact.
  • For quadratic expressions inside an absolute value, solve each case with the quadratic equation solver.

Frequently asked questions

How do you solve an absolute value equation?

Isolate the absolute value, then split |u| = k into u = k and u = −k. Solve each case and check the answers.

Why does an absolute value equation have two solutions?

Two numbers are a given distance from 0, one positive and one negative, so the expression inside can equal either of them.

When does an absolute value equation have no solution?

When the absolute value equals a negative number, or when every candidate makes the other side negative.

What is the difference between |x| < k and |x| > k?

|x| < k is the interval between −k and k. |x| > k is everything outside it: x < −k or x > k.
