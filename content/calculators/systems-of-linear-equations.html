What is a system of linear equations?

A system of linear equations is a set of equations that must all be true at once, such as \(2x + 3y = 12\) and \(x - y = 1\). Its solution is the set of values that satisfies every equation. With two unknowns, each equation is a line, and the solution is where the lines meet. With three unknowns, each equation is a plane.

Try changing the input

Make the second equation a multiple of the first, such as \(x + 2y = 4\) and \(2x + 4y = 8\). They describe the same line, so there are infinitely many solutions.

The idea behind it

Three operations never change the solutions of a system:

  1. swapping two equations;
  2. multiplying an equation by a non-zero number;
  3. adding a multiple of one equation to another.

Elimination uses them to remove one variable at a time until each equation contains a single unknown. Written in a grid of coefficients (the augmented matrix), this is Gauss–Jordan elimination.

Three possible outcomes

Exactly one solution (lines or planes meeting at a point), no solution (parallel lines), or infinitely many (the same line, or planes meeting in a line).

Why elimination works

If \((x, y)\) satisfies \(E_1\) and \(E_2\), it also satisfies \(E_1 + kE_2\): adding true equations gives a true equation. The step is reversible (subtract \(kE_2\) again), so no solutions are gained or lost. Choosing \(k\) to cancel a variable reduces the number of unknowns.

For a 2 × 2 system, eliminating \(y\) from \(a_1x + b_1y = c_1\) and \(a_2x + b_2y = c_2\) gives \((a_1b_2 - a_2b_1)x = c_1b_2 - c_2b_1\), which is Cramer's rule.

Complete worked example

Problem

Solve \(2x + 3y = 12\) and \(x - y = 1\).

Step 1: Eliminate y

Multiply the second equation by 3 and add: \(2x + 3y + 3x - 3y = 12 + 3\), so \(5x = 15\) and \(x = 3\).

Step 2: Back-substitute

\[ 3 - y = 1 \;\Rightarrow\; y = 2 \]

Check

\(2(3) + 3(2) = 12\) ✓ and \(3 - 2 = 1\) ✓.

Second worked example: three unknowns

Problem

Solve \(x + y + z = 6\), \(2x - y + z = 3\), \(x + 2y - z = 2\).

Step 1: Eliminate z

Add the first and third equations: \(2x + 3y = 8\). Subtract the first from the second: \(x - 2y = -3\).

Step 2: Solve the 2 × 2 system

From \(x = 2y - 3\): \(2(2y - 3) + 3y = 8\), so \(7y = 14\), \(y = 2\) and \(x = 1\).

Step 3: Back-substitute

\[ 1 + 2 + z = 6 \;\Rightarrow\; z = 3 \]

Check

\(2 - 2 + 3 = 3\) ✓ and \(1 + 4 - 3 = 2\) ✓.

Practical applications

  • Circuits: Kirchhoff's laws give a linear system for the loop currents.
  • Statics: force and moment balances for the reactions of a truss or beam.
  • Mixtures and blending: amounts of ingredients that meet several targets.
  • Curve fitting: the parabola through three points.

Common mistakes

  1. Multiplying only one side of an equation. Every term must be multiplied.
  2. Sign errors when subtracting equations. Subtract every term, including the right side.
  3. Stopping after one variable. Substitute back to find the others.
  4. Treating "0 = 0" as an error. It means a dependent system with infinitely many solutions.

Assumptions and limitations

  • Two or three unknowns; coefficients may be fractions or decimals, handled exactly.
  • For larger systems, use the matrix method.

Frequently asked questions

How do I solve a system of two equations?

Eliminate one variable by adding a multiple of one equation to the other, solve for the remaining variable, then substitute back.

How can I tell if a system has no solution?

Elimination produces a false statement like 0 = 5. For two equations, the lines are parallel.

What is Gauss–Jordan elimination?

Elimination done on the augmented matrix until each row has a single leading 1, so the solution can be read off directly.

Which method is best?

Substitution is quick when a variable has coefficient 1; elimination is more systematic and works for any size.
