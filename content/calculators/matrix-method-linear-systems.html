Solving linear systems with matrices

A system of linear equations can be written compactly as \(A\mathbf{x} = \mathbf{b}\), where \(A\) holds the coefficients, \(\mathbf{x}\) the unknowns and \(\mathbf{b}\) the right-hand sides. This form is how engineers solve circuit equations, truss forces and many other problems. Choose one of three matrix methods and enter the augmented matrix \([A \mid \mathbf{b}]\); every step is shown with exact fractions.

Try changing the input

Solve the same system with all three methods: the answer is identical, but the work involved differs a lot — especially as the system grows.

Methods

Gauss–Jordan elimination
Row-reduce \([A \mid \mathbf{b}]\) to \([I \mid \mathbf{x}]\). Works for every system and detects inconsistent (no solution) and dependent (infinitely many) systems.
Cramer's rule
\(x_j = \dfrac{\det A_j}{\det A}\), where \(A_j\) is \(A\) with column \(j\) replaced by \(\mathbf{b}\). Requires \(\det A \ne 0\).
Inverse matrix
\(\mathbf{x} = A^{-1}\mathbf{b}\). Also requires \(\det A \ne 0\); useful when the same \(A\) is used with many right-hand sides.

Worked example

Cramer's rule for \(3x + 2y = 16\), \(4x - y = 3\)

Step 1 — Determinant of A

\[ \det A = \begin{vmatrix} 3 & 2 \\ 4 & -1 \end{vmatrix} = -3 - 8 = -11 \]

Step 2 — Replace columns by b

\[ \det A_x = \begin{vmatrix} 16 & 2 \\ 3 & -1 \end{vmatrix} = -22, \qquad \det A_y = \begin{vmatrix} 3 & 16 \\ 4 & 3 \end{vmatrix} = -55 \]

Step 3 — Divide

\[ x = \frac{-22}{-11} = 2, \qquad y = \frac{-55}{-11} = 5 \]

Input format and limits

  • One equation per line: the coefficients followed by the right-hand side. A | before the last number is optional.
  • Square systems from 2×2 up to 6×6. If \(\det A = 0\), Cramer's rule and the inverse method cannot be used; the calculator says so and uses elimination to classify the system.
  • All arithmetic is exact.
