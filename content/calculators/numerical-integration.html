Numerical integration

Many integrals have no elementary antiderivative — \(\int e^{-x^2}\,dx\) is the famous example — and in practice data often come as a table of values rather than a formula. Numerical integration estimates \(\int_a^b f(x)\,dx\) from the values of \(f\) at evenly spaced points. This calculator applies the composite trapezoidal rule and Simpson's rule, lists every sample point and weight, and measures the error against an accurate reference value.

Try changing the input

Double \(n\) from 4 to 8: the trapezoidal error falls by about a factor of 4 and Simpson's by about 16.

Formulas

With \(h = \frac{b - a}{n}\) and \(f_i = f(a + ih)\):

\[ T = \frac{h}{2}\left[f_0 + 2f_1 + 2f_2 + \cdots + 2f_{n-1} + f_n\right] \]
\[ S = \frac{h}{3}\left[f_0 + 4f_1 + 2f_2 + 4f_3 + \cdots + 4f_{n-1} + f_n\right] \quad (n \text{ even}) \]
RuleIdeaError
TrapezoidalStraight lines between points\(-\frac{(b - a)h^2}{12}f''(\xi)\)
Simpson'sParabolas through each pair of strips\(-\frac{(b - a)h^4}{180}f^{(4)}(\xi)\)

Worked example

\(\int_0^1 e^{-x^2}\,dx\) with \(n = 4\)

Step 1 — Sample points

\(h = 0.25\): \(f(0) = 1\), \(f(0.25) \approx 0.939413\), \(f(0.5) \approx 0.778801\), \(f(0.75) \approx 0.569783\), \(f(1) \approx 0.367879\).

Step 2 — Simpson's rule

\[ S = \frac{0.25}{3}\left[1 + 4(0.939413) + 2(0.778801) + 4(0.569783) + 0.367879\right] \approx 0.746855 \]

The accurate value is \(0.746824\), so the error is only about \(3 \times 10^{-5}\). The trapezoidal rule gives 0.742984 (error about \(4 \times 10^{-3}\)).

Input validation and limits

  • \(n\) must be a whole number from 1 to 10,000; Simpson's rule requires \(n\) to be even.
  • \(f\) must be finite at every sample point; integrands with a singularity in \([a, b]\) are rejected.
  • The reference value is exact (via an antiderivative) when possible, otherwise from adaptive Simpson's rule with error about \(10^{-11}\).
