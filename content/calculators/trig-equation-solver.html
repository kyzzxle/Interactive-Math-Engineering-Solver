Solving trigonometric equations

Trigonometric functions repeat, so an equation such as \(\sin x = \tfrac{1}{2}\) has infinitely many solutions. This solver handles equations of the form \(a\,f(bx + c) + d = k\), where \(f\) is sine, cosine or tangent. It isolates the function, finds the principal value (exactly, when it is a standard angle), writes the general solution and lists every solution in one full turn, \([0, 2\pi)\) or \([0^\circ, 360^\circ)\).

Try changing the input

Change \(b\) from 1 to 2 or 3 in \(\cos(bx) = \tfrac{\sqrt{3}}{2}\): the graph oscillates faster and the number of solutions in one turn doubles or triples.

Method and general solutions

  1. Isolate the function: \(f(u) = r = \dfrac{k - d}{a}\), where \(u = bx + c\).
  2. For sine and cosine a solution exists only if \(-1 \le r \le 1\).
  3. Write all solutions for \(u\) (with \(n\) any integer):
\[ \sin u = r:\ u = \sin^{-1} r + 2\pi n \text{ or } u = \pi - \sin^{-1} r + 2\pi n \]
\[ \cos u = r:\ u = \pm\cos^{-1} r + 2\pi n \qquad \tan u = r:\ u = \tan^{-1} r + \pi n \]
  1. Solve \(u = bx + c\) for \(x\) and keep the values in the required interval.

Worked example

Solve \(2\sin x - 1 = 0\) on \([0, 2\pi)\)

Step 1 — Isolate

\[ \sin x = \frac{1}{2} \]

Step 2 — Principal value and its partner

\[ x = \frac{\pi}{6} \quad\text{or}\quad x = \pi - \frac{\pi}{6} = \frac{5\pi}{6} \]

Step 3 — General solution

\[ x = \frac{\pi}{6} + 2\pi n, \qquad x = \frac{5\pi}{6} + 2\pi n \]

Assumptions, domain and rounding

  • Supported form only: \(a\,f(bx + c) + d = k\) with \(f \in \{\sin, \cos, \tan\}\), \(a \ne 0\), \(b \ne 0\).
  • Constants may be written as expressions such as sqrt(3)/2 or pi/4; the phase \(c\) is in radians.
  • Each listed solution is checked by substitution. Standard angles are shown exactly as multiples of \(\pi\); others are rounded to 6 decimal places.
