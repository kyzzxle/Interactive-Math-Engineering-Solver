What the generating function explorer does

A generating function packs a whole counting sequence into one polynomial or power series: the coefficient of xⁿ is the number of ways to get the total n. Multiplying generating functions combines independent choices.

For example, choosing 0 to 3 apples is encoded as 1 + x + x² + x³; choosing any number of oranges as 1 + x + x² + … = 1/(1 − x). Multiply them, read off a coefficient, and you have counted.

Try it

Make change for a dollar from pennies, nickels, dimes and quarters: the coefficient of x¹⁰⁰ is 242.

Formulas and variables

\[ G(x) = \prod_i \left(x^{\min_i} + \cdots + x^{\max_i}\right) = \sum_n (\text{ways})\,x^n \]\[ \frac{1}{1 - x^c} = 1 + x^c + x^{2c} + \cdots \]
SymbolMeaning
\([x^n]\,G(x)\)Coefficient of xⁿ: the number of ways to reach total n
\(\min_i,\ \max_i\)Limits on how many of type i are chosen

With no limits on k types, the answer is the stars-and-bars number C(n + k − 1, k − 1).

Worked example

6 fruits: at most 3 apples, 1 or 2 bananas, any number of oranges

Step 1 — Generating function

\[ G(x) = (1 + x + x^2 + x^3)(x + x^2)\frac{1}{1 - x} \]

Step 2 — Count

Each choice of apples (4 ways) and bananas (2 ways) leaves exactly one number of oranges, as long as it is not negative.

Step 3 — Coefficient

\[ [x^6]\,G(x) = 8 \]

Domain, special cases and common mistakes

  • Totals up to 500; up to 8 item types or 10 coin values. Coefficients are exact integers.

Common mistakes

  • Treating items of the same type as different (only the counts matter).
  • Counting 5 + 1 and 1 + 5 as different ways of making change.
