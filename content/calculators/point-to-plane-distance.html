What the point-to-plane distance calculator does

The distance from a point to a plane is the length of the shortest segment between them, which is always perpendicular to the plane — that is, parallel to the plane’s normal vector \((A, B, C)\).

The formula projects the vector from the plane to the point onto the unit normal. The calculator keeps everything exact, so answers appear in simplest radical form, and it also finds the foot of the perpendicular.

Try it

Put a point that satisfies the plane’s equation: the numerator is 0, so the distance is 0.

Formulas and variables

\[ d = \frac{\lvert A x_0 + B y_0 + C z_0 + D \rvert}{\sqrt{A^2 + B^2 + C^2}} \]\[ F = (x_0, y_0, z_0) - t\,(A, B, C),\quad t = \frac{A x_0 + B y_0 + C z_0 + D}{A^2 + B^2 + C^2} \]
SymbolMeaning
\(A,\ B,\ C,\ D\)Coefficients of the plane Ax + By + Cz + D = 0
\((x_0, y_0, z_0)\)The point
\(F\)Foot of the perpendicular (nearest point on the plane)

Worked example

Point P(1, 4, 5) and plane 2x − y + 2z − 3 = 0

Step 1 — Substitute

\[ 2(1) - 4 + 2(5) - 3 = 5 \]

Step 2 — Length of the normal

\[ \sqrt{2^2 + (-1)^2 + 2^2} = 3 \]

Step 3 — Distance

\[ d = \frac{|5|}{3} = \frac{5}{3} \]

Domain, special cases and common mistakes

  • A, B and C cannot all be 0.
  • Fractions are allowed and kept exact; the result is in simplest radical form.

Common mistakes

  • Forgetting to move everything to one side (= 0) before reading D.
  • Dropping the absolute value, giving a negative distance.
